# Обмінне сортування зі злиттям Бетчера (Haskell, багатопотоковість)

Реалізація алгоритму Бетчера `merge-exchange sort` (ітеративна форма алгоритму M)
у вигляді сортувальної мережі. Мережа будується як послідовність етапів; на кожному
етапі виконуються попарні порівняння з обміном. Пари одного етапу не перетинаються,
тому їх можна виконувати одночасно.

Програма створює рівно `k` потоків Haskell (`forkIO`) і розподіляє порівняння кожного
етапу між ними. Після кожного етапу потоки синхронізуються через бар'єр на `MVar`.

## Збірка та запуск

```bash
ghc -threaded -O2 -Wall Main.hs -o batcher
./batcher +RTS -N -RTS          # -N — використати всі доступні ядра
./batcher +RTS -N4 -RTS         # або явно задати кількість ядер
```

Ключ `-threaded` обов'язковий: без нього потоки Haskell не виконуються на кількох
ядрах. Щоб побачити реальне прискорення, запускайте з `+RTS -N... -RTS`.

## Ввід

З клавіатури послідовно вводяться:

1. `k` — кількість потоків (ціле число > 0);
2. `n` — кількість елементів масиву (ціле число > 0);
3. самі елементи — через пробіл в одному рядку або в кілька рядків.

Приклад:

```text
Кількість потоків k: 4
Кількість елементів n: 8
Введіть елементи масиву: 5 3 8 1 -2 7 3 0
```

```text
Відсортований:      -2 0 1 3 3 5 7 8
Перевірка:          OK
Потоків: 4 | етапів: 6 | порівнянь: 19
```

## Особливості

- Працює для будь-якого `n`, а не лише для ступеня двійки (`p0 = 2^floor(lg n)`).
- Глибина мережі — `O(log² n)`, загальна кількість порівнянь — `O(n log² n)`.
- Перевірка коректності (`sorted == Data.List.sort`) виводиться автоматично.
- Можна ввести `k > n` — зайві потоки просто отримають порожні порції роботи.
